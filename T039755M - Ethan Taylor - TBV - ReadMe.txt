Disclaimer
The system does work at all sizes (that I have tested) however due to UE’s systems without turning some of them off it will through an infinite loop error. You will know this is happening if it takes more than 10 seconds to load after hitting play. 
There is no collision for the environment because this project is to showcase a map generation system, so I didn’t add any collisions. 
I recommend using 25 or 50 for the node size and sticking to .5s or .0s for the size of the chunks. Also don’t go to big with the size of the chunk.
